# 战斗追踪器（Combat Tracker）

## 1. 背景

coccard 应用已有完整的武器管理（`WeaponPage`）、伤害加值（DB/体格）、HP/MP 追踪、以及战斗规则参考表（`ReferencePage` 的战斗类条目）。但在实际跑团场景中，守秘人最需要的是一个能**实时追踪战斗轮次**的工具——当前应用缺少这一环节，守秘人只能手动在纸上或第三方工具里记录行动顺序、各角色和敌人的 HP 变化、以及受伤/濒死状态。

本提案设计一个**轻量战斗追踪器**，集成在 coccard 应用内，面向守秘人（Keeper），帮助在移动设备上管理一场战斗的所有关键信息。

## 2. 用户故事

### 守秘人视角

- US-1：作为守秘人，我希望快速创建一场战斗，添加参战的玩家角色和敌人，按 DEX 排序行动顺序。
- US-2：作为守秘人，我希望在战斗中随时修改任何参战者的 HP，应用自动标记受伤/濒死/死亡状态。
- US-3：作为守秘人，我希望为敌人临时创建 NPC 卡片（名称、HP、攻击力），不需要完整角色卡。
- US-4：作为守秘人，我希望战斗结束后查看战斗摘要（持续轮数、伤害总量、倒地角色），并保存到本地。
- US-5：作为守秘人，我希望在战斗中快速投骰（攻击、伤害、检定），结果直接关联到当前选中的参战者。
- US-6：作为守秘人，我希望标记参战者的特殊状态（昏迷、逃跑、恐惧、临时疯狂）。

### 玩家视角

- US-7：作为玩家，如果守秘人共享屏幕，我能清晰看到行动顺序和自己的 HP 变化。

## 3. 范围与非目标

### 一期范围

- 创建/管理战斗实例（一场战斗 = 一个 `CombatEncounter`）。
- 参战者列表：支持添加当前角色卡 + 临时 NPC。
- 行动顺序：按 DEX 自动排序，支持手动调整。
- HP 追踪：实时修改，自动计算受伤/濒死/死亡。
- 特殊状态标记：昏迷、逃跑、恐惧等。
- 战斗轮次计数器。
- 战斗摘要（轮数、伤害总量）。
- 本地持久化（SharedPreferences）。

### 非目标（后续迭代）

- 多角色参战（一期只支持当前选中角色 + NPC 敌人）。
- 联机同步战斗状态。
- 自动投骰结算（一期手动投骰 + 手动输入结果）。
- 战斗动画/音效。
- 与骰点历史（`DiceRollRecord`）集成。

## 4. 数据模型

### 4.1 CombatEncounter（战斗实例）

```dart
class CombatEncounter {
  final String id;            // UUID
  String name;                // 战斗名称，如"图书馆遭遇战"
  List<Combatant> combatants; // 参战者列表
  int currentRound;           // 当前轮次
  int currentTurnIndex;       // 当前行动者的索引
  CombatStatus status;        // ongoing / finished
  DateTime createdAt;
  DateTime? finishedAt;

  // 摘要统计
  int get totalRounds => currentRound;
  int get totalDamageDealt => combatants.fold(0, (sum, c) => sum + c.damageTaken);
}
```

### 4.2 Combatant（参战者）

```dart
class Combatant {
  final String id;           // UUID
  String name;               // 显示名称
  CombatantType type;        // playerCharacter / npc
  String? characterId;       // 关联的角色卡 ID（仅 playerCharacter）
  int dex;                   // 决定行动顺序
  int maxHp;
  int currentHp;
  List<CombatantStatus> statuses; // 特殊状态列表
  bool isAlive;              // currentHp > 0
  bool isUnconscious;        // currentHp == 0 且无重大伤口 → 昏迷
  bool isDying;              // currentHp == 0 且有重大伤口 → 濒死
  int damageTaken;           // 累计受伤值（用于战斗摘要）
  String? notes;             // 守秘人备注
}
```

### 4.3 枚举

```dart
enum CombatStatus { ongoing, finished }

enum CombatantType { playerCharacter, npc }

enum CombatantStatus {
  unconscious,   // 昏迷（HP=0，无重大伤口）
  dying,         // 濒死（HP=0，有重大伤口）
  fled,          // 逃跑
  frightened,    // 恐惧
  temporaryMadness, // 临时疯狂
  dead,          // 死亡
}
```

### 4.4 JSON 序列化

所有模型需实现 `toJson()` / `fromJson()`，默认值保证旧数据兼容：

```dart
// Character 新增字段（可选，一期可以只存 combat encounters）
List<CombatEncounter> combatHistory; // 默认 []
```

## 5. 控制器/服务层

### CombatController（ChangeNotifier）

```dart
class CombatController extends ChangeNotifier {
  final SharedPreferences _prefs;

  // 当前战斗
  CombatEncounter? _currentEncounter;
  CombatEncounter? get currentEncounter => _currentEncounter;

  // 历史战斗
  List<CombatEncounter> _history = [];
  List<CombatEncounter> get history => _history;

  // 创建战斗
  void createEncounter(String name, List<Combatant> combatants);

  // 添加参战者
  void addCombatant(Combatant combatant);

  // 移除参战者
  void removeCombatant(String combatantId);

  // 修改 HP
  void modifyHp(String combatantId, int delta);

  // 切换状态
  void toggleStatus(String combatantId, CombatantStatus status);

  // 下一个行动者
  void nextTurn();

  // 回合开始（轮次 +1，重置 turnIndex）
  void nextRound();

  // 结束战斗
  void finishEncounter();

  // 持久化
  void _save();
  void _load();
}
```

## 6. UI 设计

### 6.1 入口

- `HomePage` AppBar 或 `AppDrawerWidget` 新增「⚔️ 战斗」入口。
- 路由：`/combat`。

### 6.2 战斗列表页（CombatListPage）

- 顶部「新建战斗」按钮。
- 列表显示历史战斗：名称、轮数、参战者数量、状态（进行中/已结束）。
- 进行中的战斗可点击继续。

### 6.3 战斗主页面（CombatPage）

顶部 AppBar：
- 战斗名称 + 轮次计数器（如「第 3 轮」）。
- 「+ 添加参战者」按钮。
- 「结束战斗」按钮。

主体区域分三块：

**行动顺序条**（水平滚动）：
- 圆形头像 + 名称首字。
- 当前行动者高亮。
- 点击切换选中。

**当前行动者详情卡片**：
- 名称、类型（PC/NPC）、DEX。
- HP 滑块或 +/- 按钮，颜色随 HP 变化（绿→黄→红→灰）。
- 状态标签（可点击切换）。
- 备注输入框。

**参战者列表**（可展开）：
- 每人一行：头像、名称、HP 条、状态图标。
- 点击展开详情。
- 左滑删除（NPC）或退出（PC）。

底部操作栏：
- 「🎲 投骰」快捷按钮（复用 `DiceRollerWidget`）。
- 「下一位」按钮（推进行动顺序）。
- 「下一轮」按钮（轮次 +1）。

### 6.4 添加参战者弹窗

两个 Tab：
- **从角色卡添加**：显示 `CharacterManager` 中已有的角色列表，选择后自动填入名称、HP、DEX。
- **新建 NPC**：表单——名称、DEX、HP、备注。

### 6.5 战斗摘要页

战斗结束后弹出：
- 战斗名称、持续轮数。
- 参战者列表：每人最终 HP、受伤总量、状态。
- 「保存」和「丢弃」按钮。

## 9. 兼容性与迁移

- `Character` 不修改现有字段，一期 `CombatEncounter` 独立存储在 SharedPreferences 中（key: `combat_encounters`）。
- 如果后续需要将战斗记录关联到角色，可在 `Character.combatHistory` 中增加引用列表。
- 不影响现有的 `SkillCheckRecord`、`InsanityEpisode`、`DiceRollRecord` 等数据结构。
- `AppDrawerWidget` 新增入口时使用 `Icons.swords` 图标（Flutter Material Icons）。

## 10. 风险与缓解

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| 战斗数据量大（长战斗 50+ 轮） | SharedPreferences 写入变慢 | 限制历史记录保留最近 20 场战斗 |
| HP 修改频繁触发 notifyListeners | 列表重建过多 | 使用 `AnimatedBuilder` 局部重建，或延迟保存（debounce） |
| 多角色参战（二期）数据模型需扩展 | 数据结构变更 | `Combatant.characterId` 已预留多角色关联 |
| 战斗中角色卡被修改 | HP/DEX 不同步 | 战斗开始时复制快照，不实时同步角色卡变更 |
